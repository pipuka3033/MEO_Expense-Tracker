## Описание
Графическое приложение **Training Planner** предназначено для планирования и учета тренировок. Приложение позволяет пользователю добавлять записи о тренировках, просматривать их в виде таблицы, а также фильтровать данные по типу активности и дате. Все данные сохраняются в локальном файле формата JSON, что обеспечивает сохранение информации между запусками программы.

## Функциональные возможности
1. **Добавление тренировки:**
   - Ввод даты (в формате ДД.ММ.ГГГГ).
   - Выбор типа тренировки из списка (Бег, Плавание, Силовая, Йога, Велосипед).
   - Указание длительности в минутах.
2. **Валидация ввода:**
   - Проверка формата даты.
   - Проверка того, что длительность является положительным целым числом.
3. **Просмотр данных:**
   - Отображение списка тренировок в табличном виде.
4. **Фильтрация:**
   - Фильтр по типу тренировки.
   - Фильтр по дате (поиск по подстроке).
5. **Управление данными:**
   - Автоматическое сохранение в `workouts.json`.
   - Загрузка данных при старте приложения.
   - Возможность удаления выбранных записей.

## Примеры использования
1. **Добавление тренировки:**
   - В поле "Дата" убедитесь, что дата указана верно (например, 12.05.2026).
   - Выберите тип тренировки, например, "Бег".
   - Введите длительность, например, 45.
   - Нажмите кнопку "Добавить тренировку".
   - Если ввод корректен, появится сообщение об успехе, и запись добавится в таблицу.
## Фильтрация
1. В блоке "Фильтрация" выберите тип, например, "Силовая". В таблице останутся только силовые тренировки.
2. В поле даты введите 05, чтобы увидеть все тренировки за май (или любой другой месяц/год, содержащий '05').
