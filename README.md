## Описание программы
Графическое приложение на Python (Tkinter) для отслеживания личных расходов. 
Приложение позволяет добавлять расходы, указывая сумму, категорию и дату. 
Данные сохраняются в формате JSON. Реализована возможность фильтрации расходов по категории и периоду времени, а также подсчет общей суммы расходов за выбранный период.

**Особенности:**
- **Надежная валидация:** Проверка на пустые поля, корректность чисел и формат даты.
- **Уникальные ID:** Используется `uuid4` для идентификации записей, что исключает конфликты при удалении.
- **Гибкая фильтрация:** Можно комбинировать фильтр по категории и диапазону дат.

## Требования
- Python 3.6+
- Стандартные библиотеки: `tkinter`, `json`, `datetime`, `os`, `uuid`
