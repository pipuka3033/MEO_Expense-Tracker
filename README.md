# Expense Tracker (Трекер расходов)

## Автор
Уразов Артем

## Описание программы
Графическое приложение на Python (Tkinter) для отслеживания личных расходов. 
Приложение позволяет добавлять расходы, указывая сумму, категорию и дату. 
Данные сохраняются в формате JSON. Реализована возможность фильтрации расходов по категории и периоду времени, а также подсчет общей суммы расходов за выбранный период.

## Функциональность
1. **Добавление расхода**: Ввод суммы, выбор категории из списка, ввод даты.
2. **Валидация ввода**: 
   - Сумма должна быть положительным числом.
   - Дата должна быть в формате ДД.ММ.ГГГГ.
3. **Просмотр истории**: Таблица всех добавленных расходов.
4. **Фильтрация**: 
   - По категории (Еда, Транспорт и т.д.).
   - По диапазону дат (с ... по ...).
5. **Подсчет итогов**: Автоматический пересчет суммы расходов в соответствии с примененными фильтрами.
6. **Удаление**: Возможность удалить выбранную запись.
7. **Сохранение данных**: Все данные автоматически сохраняются в файл `expenses.json` и загружаются при запуске.

## Требования
- Python 3.6+
- Стандартные библиотеки: `tkinter`, `json`, `datetime`, `os`
